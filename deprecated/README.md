# Carpeta legacy (archivos del proyecto anterior)

Este directorio contiene módulos, scripts y artefactos del proyecto anterior.
Se mantienen solo con fines históricos y **no son compatibles con la nueva solución**.

⚠️ **No deben modificarse, ejecutarse ni importarse desde el código actual.**

Motivos:
- La arquitectura del nuevo producto cambió completamente.
- Las APIs, modelos y flujos previos quedaron obsoletos.
- Varias dependencias ya no existen en la versión actual.

Si necesitás revisar estos archivos, hacerlo únicamente como referencia histórica.
